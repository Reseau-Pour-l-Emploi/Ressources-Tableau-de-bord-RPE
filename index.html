Glossaire du tableau de bord RPE

Dimensions (variables d'analyse) et mesures (indicateurs) du Réseau Pour l'Emploi
Connexion administrateur
Comment lire ce glossaire. Une dimension sert à filtrer ou croiser les données. Une mesure est une valeur chiffrée utilisée dans un calcul. Le nom technique dans la base apparaît en infobulle au survol du libellé. Un groupe (tag orange) rassemble des données aux définitions proches (ex. toutes les mesures "Accès à l'emploi") : cliquez dessus pour voir les autres membres. Une variable hiérarchique (tag bordeaux) signale que la donnée existe à d'autres niveaux d'agrégation d'un même référentiel (ex. Catégorie juridique niv1/niv2/niv3) : le détail permet de naviguer entre les niveaux.

Une donnée manquante ou incomplète ? Ce glossaire est contributif.

Vous pouvez proposer l'ajout d'une donnée absente, ou la modification/suppression d'une donnée existante (icônes 📝 et 🗑️ dans le détail de chaque fiche). Chaque demande d'évolution est examinée individuellement par un administrateur avant publication.
