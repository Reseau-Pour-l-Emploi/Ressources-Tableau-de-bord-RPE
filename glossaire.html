📖 Mode d'emploi

🏷️ Une dimension sert à filtrer ou croiser les données. Une mesure est une valeur chiffrée utilisée dans un calcul. Le nom technique dans la base apparaît en infobulle au survol du libellé.

🗝️ Un KPI est un indicateur stratégique défini par le Comité National pour l'Emploi, signalé par l'icône 🗝️ (si un des éléments d'un groupe est KPI, le groupe l'est aussi). 📄 Indicateur désigne une donnée présente sur une page de synthèse ; 🗂️ Champ désigne un champ disponible pour construire un tableau personnalisé - seul ce dernier porte une étiquette Dimension/Mesure, et les groupes/hiérarchies ne concernent que les champs. Le filtre "Nature de fiche" permet d'afficher l'un, l'autre, ou seulement les KPI. Les pages ne sont pas des fiches du glossaire : uniquement un filtre - sélectionner une page affiche sa définition, et l'étiquette d'une page révèle cette même définition au survol.

🧩 Un groupe rassemble des données aux définitions proches (ex. toutes les mesures "Accès à l'emploi") : une seule fiche apparaît dans la liste, cliquez dessus pour voir tous les membres.

🪜 Une variable hiérarchique signale que la donnée existe à d'autres niveaux d'agrégation d'un même référentiel (ex. Catégorie juridique niv1/niv2/niv3, avec ex æquo possibles). Seul le niveau le plus détaillé apparaît dans la liste ; son détail permet de naviguer entre tous les niveaux.

🔍 La recherche porte sur le libellé et le nom technique. Si le mot-clé correspond à une donnée cachée (membre d'un groupe, ou niveau hiérarchique masqué), c'est la fiche visible correspondante (le groupe, ou le niveau le plus détaillé) qui remonte dans les résultats.

🔗 Le bouton partager (icône) copie un lien direct vers la définition, utilisable par n'importe qui pour la retrouver instantanément.

✍️ Ce glossaire est contributif : proposez un ajout, une modification ou une suppression (icônes 📝 / 🗑️ dans le détail de chaque fiche), ou définissez en une seule fois un groupe ou une hiérarchie pour plusieurs champs à la fois. Chaque demande est examinée par un administrateur avant publication.

Une donnée manquante ou incomplète ? Ce glossaire est contributif.

Vous pouvez proposer l'ajout d'une donnée absente, ou la modification/suppression d'une donnée existante (icônes 📝 et 🗑️ dans le détail de chaque fiche). Vous pouvez aussi définir en une seule fois un groupe ou une hiérarchie et sélectionner directement tous les champs concernés, plutôt que d'ouvrir chaque fiche une par une. Chaque demande d'évolution est examinée individuellement par un administrateur avant publication.

Définir un groupe ou une hiérarchie

Sélectionnez un groupe existant (ou tapez son nom puis "Charger") pour voir/modifier ses champs. Les champs déjà assignés sont pré-cochés : cochez-en de nouveaux ou décochez-en pour les retirer.
Sélectionnez une hiérarchie existante (ou tapez son nom puis "Charger") pour voir/modifier ses niveaux. Ajoutez un niveau par ligne, du plus agrégé (en haut) au plus détaillé (en bas). Plusieurs champs cochés sur un même niveau = ex æquo.
Cette proposition sera soumise à validation avant publication dans le glossaire.
